> **An interactive, gamified learning adventure through the Gospel of John. Created by James S.**

Welcome to **Journey Through John**! This interactive web application is designed to help kids (and adults!) learn and remember the 21 chapters of the Gospel of John[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2F2ndchances520.github.io%2FJourneyThroughJohn%2F)]. With fun mini-games, unlockable chapters, and a progression system, learning Scripture has never been this engaging.

🌐 **[Play the Live Demo Here!](https://2ndchances520.github.io/JourneyThroughJohn/)**

---

## ✨ Features

* **🗺️ 21 Unlockable Chapters:** Journey from *The Word Became Flesh* (Chapter 1) all the way to the *Breakfast by the Sea* (Chapter 21)[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2F2ndchances520.github.io%2FJourneyThroughJohn%2F)]. 
* **🪙 Gamified Progression:** Earn "Faith Tokens" by completing challenges. You need at least 30 tokens in a chapter to unlock the next one![[1](https://www.google.com/url?sa=E&q=https%3A%2F%2F2ndchances520.github.io%2FJourneyThroughJohn%2F)]
* **🎮 3 Unique Mini-Games per Chapter:**
  * **Quiz:** Multiple-choice questions testing reading comprehension[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2F2ndchances520.github.io%2FJourneyThroughJohn%2F)].
  * **Verse Fill-in:** A word-bank challenge to complete the chapter's Key Verse[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2F2ndchances520.github.io%2FJourneyThroughJohn%2F)].
  * **Order Events:** A drag-and-drop (and touch-friendly) timeline game to put the events of the chapter in chronological order[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2F2ndchances520.github.io%2FJourneyThroughJohn%2F)].
* **💾 Auto-Saving:** Progress is saved automatically directly in your browser using `localStorage`. Pick up exactly where you left off![[1](https://www.google.com/url?sa=E&q=https%3A%2F%2F2ndchances520.github.io%2FJourneyThroughJohn%2F)]
* **🛠️ Built-in Self-Testing:** The app runs a seamless background check on boot to ensure all 21 chapters, quizzes, and arrays are functioning perfectly[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2F2ndchances520.github.io%2FJourneyThroughJohn%2F)].

## 🛠️ Tech Stack

This project is lightweight, lightning-fast, and built entirely without heavy frameworks. 

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6)
* **Data Management:** LocalStorage API
* **Interactivity:** Native HTML5 Drag and Drop API (with custom touch support for mobile devices)[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2F2ndchances520.github.io%2FJourneyThroughJohn%2F)]
